Problem Statement

Four critical systemic failures plaguing modern data pipelines and enterprise analytics workflows.

Pitfall 01

Archive Fragility

Pipelines crash on multi-dataset ZIP uploads due to payload limits (HTTP 413), directory traversal attacks, or unhandled nested compression.

Pitfall 02

Binder SQL Errors

LLM text-to-SQL generators hallucinate column names, resulting in fatal database binder exceptions and broken automated dashboard reports.

Pitfall 03

Feature Leakage

Automated ML pipelines fail to verify temporal boundaries, accidentally training on future attributes and producing dangerously overfitted models.

Pitfall 04

Destructive Edits

Existing ETL cleaning scripts overwrite raw source tables, creating irreversible data loss, audit compliance violations, and untraceable lineages.

Why traditional data stacks (dbt + Airflow), commercial AutoML, and generic AI assistants fail enterprise requirements.

Black-Box Cost Traps

Ungrounded Code Generation

  • Zero execution sandboxing or runtime verification guarantees.
  • Frequently resorts to fake or mocked metrics in UI visualizers.

Proposed System — MK-Path Architecture

An evidence-gated, deterministic, multi-agent platform designed for complete end-to-end autonomy.

Core Pillar 01 & 02

Intelligent Ingestion & Semantic Ontologies

  • 500 MB Safe Archive Ingestion: Decompresses nested ZIPs with zip-bomb safeguards, converts tables to Parquet, and mounts DuckDB views instantly.
  • Zero-LLM Profiling Engine: Fast C++ vectorized computation of null counts, uniqueness, and deterministic quality scores (0-100).
  • Semantic Knowledge Discovery: Automatically builds concept ontologies, linking natural language goals to physical column realities.
Core Pillar 03 & 04

Multi-Agent Collaboration & Self-Healing

  • Agent Collective: Analyst generates zero-binder SQL; Scientist runs Pareto tournaments; Engineer builds production deployment packages.
  • Verification Gates: Deterministic PASS / FAIL / HUMAN_REVIEW checkpoints halt pipeline progression upon data leakage or score degradation.
  • Non-Destructive Healing: Produces healed derived Parquet views while raw uploaded datasets remain 100% byte-identical.

Core Functional Modules

Six tightly integrated architectural layers working collaboratively without human intervention.

Module 01

Ingestion & Model Builder

Multi-format support (`.csv`, `.tsv`, `.json`, `.parquet`, `.xlsx`, `.sql`, `.zip`). Enforces strict traversal sanitization and auto-registers DuckDB views (`ds_`).

Module 02

Deterministic Profiler

Computes exact column types, missingness, and quality grades (A-F). Zero external API calls, zero token costs, 100% reproducible.

Module 03

Semantic Ontology & Breakpoint

Identifies dimensions and metrics. Enters a human-in-the-loop breakpoint only when severe target ambiguity is detected.

Module 04

Empirical Data Analyst

Translates user objectives into DuckDB SQL aggregations. Extracts volume drivers, variance benchmarks, and strategic decision matrices.

Module 05

Model Tournament Engine

Auto-detects classification vs. regression. Trains Logistic Regression, Random Forest, and LightGBM with pre-scaled pipelines and Pareto ranking.

Module 06

Autonomous Healing Engine

Synthesizes safe transformations (imputation, type-coercion) applied to derived Parquet models, maintaining strict cryptographic source integrity.
